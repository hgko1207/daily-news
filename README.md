# daily-news

> Claude가 매일 아침 정리하는 개인 브리핑 아카이브

국내 경제, 글로벌 기술, 개발자 소식, 교양·생활, 투자, 오늘의 말씀까지 6개 주제의 브리핑이 매일 마크다운 파일로 쌓입니다. 사람이 손대지 않아도 매일 자동으로 작성되고 커밋됩니다.

- 시작일: 2026-07-01
- 갱신: 매일 오전 10시 무렵 (KST)
- 모바일 앱(PWA): **https://hgko1207.github.io/daily-news/** (폰에서 열고 설정 → 앱 설치 방법 참고)

---

## 어떻게 만들어지나

```
Claude Desktop 스케줄러 (매일 ~10:00 KST)
  └─ 웹에서 뉴스·시세·트렌드 조사
  └─ 카테고리별 브리핑을 마크다운으로 작성
  └─ git commit "뉴스 아카이브 YYYY-MM-DD" → push
```

- 커밋 메시지는 `뉴스 아카이브 YYYY-MM-DD` 형식입니다.
- 모든 내용은 **AI가 작성**합니다. 수치에는 기준 시점(장중/종가)과 출처 링크를 함께 적지만, 실시간 시세와 다를 수 있습니다.
