### 1. Bumblebee — Perplexity가 공개한 공급망 스캐너

**요약**
Perplexity AI가 내놓은 읽기 전용(read-only) 공급망 스캐너. 프로젝트의 의존성뿐 아니라 **MCP 서버와 에디터 확장(extension)까지** 훑어 수상한 패키지를 몇 초 만에 잡아낸다. v0.1.1(2026년 5월) 이후 빠르게 성장해 약 2.6k 스타 수준의 초기 단계 프로젝트.

**왜 눈여겨볼지**
지금까지 공급망 보안 도구는 `package.json` / `requirements.txt`만 봤다. MCP 서버와 VS Code 확장은 로컬 파일 접근·네트워크 권한을 가진 실행 코드인데도 감사 사각지대였다. Claude Code나 Cursor에 MCP를 여러 개 붙여 쓰는 개발자라면 지금 딱 필요한 도구다. 초기 단계 프로젝트라 오탐(false positive)은 감안할 것.

### 2. Block(잭 도시)의 셀프호스팅 Slack+GitHub 대체재 — AI 에이전트가 '채널 멤버'

**요약**
잭 도시의 Block에서 나온 무료·셀프호스팅 가능한 협업 도구. AI 에이전트가 봇으로 옆에 붙는 게 아니라 **채널의 실제 멤버**로 존재한다 — 고유 아이덴티티, 고유 권한, 고유 감사 로그(paper trail)를 갖는다.

**왜 눈여겨볼지**
"봇 토큰 하나로 모든 걸 하는" 기존 방식의 한계를 정면으로 겨냥한 설계다. 에이전트별 권한 분리와 감사 추적은 사내 도입 시 보안팀이 가장 먼저 묻는 질문이기도 하다. 사내 AI 에이전트 도입을 검토 중이라면 아키텍처 참고용으로 볼 가치가 있다.

### 3. D2 / DevToys — 꾸준히 트렌딩에 오르는 실무 도구

**요약**
**D2**는 간단한 스크립트 언어로 다이어그램을 만드는 도구. 드래그앤드롭 없이 텍스트로 아키텍처·워크플로 문서화가 가능하다. **DevToys**는 JSON 포매팅, 인코딩/디코딩, 정규식 테스트 등 수십 개 유틸리티를 오프라인 데스크톱 앱 하나로 묶었다.

**왜 눈여겨볼지**
둘 다 "diff로 관리 가능한 문서화"와 "웹에 붙여넣지 않는 데이터 처리"라는, AI 시대에 오히려 중요해진 가치를 담고 있다. 사내 데이터를 온라인 JSON 포매터에 붙여넣는 습관이 있다면 DevToys로 바꾸는 것만으로 리스크가 줄어든다.

### 5. GitHub Copilot, 사용량 기반 과금으로 전면 전환 (6/1 시행)

**요약**
GitHub는 2026년 6월 1일부터 Copilot을 사용량 기반 과금으로 전환했다. **1 AI Credit = $0.01**이며 월정액 플랜의 프리미엄 요청 할당량은 폐지. 플랜별 월 크레딧은 Pro 1,500 / Pro+ 7,000 / 신설 Max 20,000. Cursor 개인 플랜은 Hobby(무료) / Pro $20 / Pro+ $60 / Ultra $200 구조.

**왜 눈여겨볼지**
업계 전체가 "정액 무제한" → "크레딧 소진" 모델로 이동했다. 에이전트형 워크플로는 한 번의 작업이 수십 번의 모델 호출을 유발하므로, 체감 비용이 정액제 시절과 완전히 달라진다. 도구 선택 기준에 "월 요금"이 아니라 "내 작업 1건당 크레딧 소모량"을 넣어야 하는 시기.
