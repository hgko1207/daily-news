## 2. GitLab.com 레이트 리밋 정책 변경

- **요약**: GitLab이 GitLab.com의 요청 제한(rate limit) 정책 변경을 공지했다. HN 115점·92개 댓글로 논쟁이 활발하다.

- 📄 링크: https://about.gitlab.com/blog/rate-limit-change-2026/ / https://news.ycombinator.com/item?id=49742353

- 📄 링크: https://www.crowdsec.net/blog/crowdsec-statement-source-code-exposure

- **요약**: 이날 HN에 **Skillsync(YC W26)** 런치가 올라왔다 — AI 채팅 세션을 여러 에이전트 사이에서 옮겨 쓸 수 있게 만드는 도구. 같은 날 에이전트용 skill을 큐레이션해 모은 **skillbay.sh**, 개인 AI 셋업을 공유하는 **mysetup.ai**(126점)도 함께 올라왔다.

- 📄 링크: https://news.ycombinator.com/item?id=49743049 / https://skillbay.sh/ / https://mysetup.ai/

### 2. GitHub Trending — AI 에이전트 툴링이 상위권 독식

- **요약**: 9월 둘째 주 GitHub Trending 집계에서 에이전트용 skill·툴링 저장소가 상위권을 차지했다는 정리가 나왔다. 대표적으로 에이전트 출력에서 결론을 먼저 말하게 강제하는 skill인 `i-have-adhd`가 1위권(약 16.5k stars 획득)으로 보고됐고, Microsoft `markitdown`, Tencent `teamai-cli` 등이 신규 진입으로 언급됐다.

- ⚠️ **출처 주의**: 순위·스타 수치는 주간 큐레이션 블로그 집계로, GitHub 공식 통계와 차이가 있을 수 있습니다. 정확한 현황은 github.com/trending에서 직접 확인을 권합니다.
