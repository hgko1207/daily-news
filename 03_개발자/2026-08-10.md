### 3. GitHub Actions 장애 (8/6) & 신규 모델 소식
**요약:** 8월 6일 GitHub Actions가 워크플로 지연·실패로 가용성 저하를 겪었고 Pages도 간헐적 성능 저하를 보였다. 한편 OpenAI는 ChatGPT의 GPT-5.6 'Sol'을 업데이트해 답변 집중도·정확도를 개선하고 사고량(thought-level) 슬라이더를 Plus/Pro에 제공했다.
**왜 눈여겨볼지:** CI/CD가 외부 서비스에 묶여 있을 때의 리스크(장애 대응 플랜)와, 사용자가 추론 강도를 조절하는 UX 트렌드를 함께 보여준다.
