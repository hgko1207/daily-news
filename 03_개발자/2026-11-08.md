### 1. libghostty-vt 1.0 — 터미널 에뮬레이션 C 라이브러리 정식판 (HN 950pts)
- **요약:** Ghostty 터미널의 코어를 떼어 낸 C 라이브러리가 1.0으로 안정화됐다. 엄격한 ABI 호환 정책(CI에서 ABI 변경 검사), MIT 라이선스, libc만 의존(프리스탠딩 빌드 가능)하고 Linux·macOS·Windows·iOS·Android·WASM을 지원한다. JetBrains IDE 터미널이 이미 사용 중이고 Neovim도 도입을 준비 중이다.
- **왜 눈여겨볼지:** 웹·데스크톱 앱에 터미널을 붙이거나, 에이전트용 터미널 UI를 만들 때 에뮬레이터를 직접 짤 필요가 줄어든다. 'opaque handle + enum 키 getter/setter'로 ABI를 지키는 설계는 C API 설계 교과서로도 읽을 만하다.
- 📄 [mitchellh.com](https://mitchellh.com/writing/libghostty-1-0) · [Hacker News](https://news.ycombinator.com/)

### 5. (AI 코딩 도구) Claude Code v2.1.319 — MCP 백그라운드 작업, 'deny instead of prompting'
- **요약:** MCP 서버가 도구 호출을 task로 돌리면 Claude Code가 백그라운드로 넘기고 끝나면 결과를 알려 준다. `permissions.denyInsteadOfPrompting` 설정을 켜면 권한 프롬프트를 기다리지 않고 거부한 뒤 턴을 계속 진행한다. 직전 버전들에서는 `blockWritesOutsideWorkingDirectories`(작업 폴더 밖 쓰기 차단)와 `CLAUDE_CODE_SUBAGENT_EFFORT`가 추가됐고, Opus 4.8 fast mode는 11/30에 제거될 예정이다.
- **왜 눈여겨볼지:** 무인 실행(CI·스케줄 작업)에서 권한 프롬프트 때문에 멈추는 문제를 줄여 준다. Opus 4.8 fast mode를 쓰는 스크립트가 있다면 11월 안에 바꿔야 한다.
