## 2. Hacker News — macOS 27에서 `hdiutil` deprecated

**요약**
2026년 8월 23일(일) 기준 HN 프론트페이지 1위는 **"hdiutil is deprecated in macOS 27 Golden Gate"**였다. `hdiutil`은 macOS에서 디스크 이미지(.dmg)를 생성·마운트·변환하는 오래된 CLI 유틸리티다.

**왜 눈여겨볼지**
macOS 배포 파이프라인을 CI에서 돌리고 있다면 직접적인 영향이 있다. `.dmg` 패키징, 코드사이닝, 노터라이제이션 스크립트 대부분이 `hdiutil`을 호출한다. deprecation은 보통 1~2 메이저 버전의 유예를 주지만, CI 러너 이미지가 먼저 올라가면 예고 없이 빌드가 깨지는 형태로 체감된다. 지금 대체 경로를 확인해두는 편이 낫다.

## 3. ripgrep, musl 링크 바이너리에서 SIGSEGV 크래시

**요약**
매우 큰 파일 트리를 대상으로 musl로 링크된 ripgrep 바이너리를 실행할 때 SIGSEGV로 크래시하는 버그 리포트가 HN에서 화제가 됐다. 문제는 musl의 allocator 내부 `calloc` 호출에서 발생하며, glibc로 링크된 바이너리에서는 재현되지 않는다. ripgrep 작성자가 버그를 확인했다.

**왜 눈여겨볼지**
Alpine 기반 컨테이너 이미지를 쓰는 경우 남 일이 아니다. Alpine은 musl을 쓰기 때문에, "로컬에서는 되는데 컨테이너에서만 죽는" 유형의 버그가 바로 이 계열이다. 성능·이미지 크기 때문에 Alpine을 선택했다면, 대용량 워크로드에서는 glibc 기반(debian-slim 등) 이미지와 한 번쯤 비교 테스트해볼 가치가 있다.

## 4. npm 공급망 공격 — keyv발 웜, 353개 오염 버전

**요약**
자격증명을 탈취하는 npm 웜이 **keyv@6.0.0**에서 처음 발견돼 수백 개 패키지로 확산됐다. SafeDep은 79개 패키지명에 걸쳐 **353개의 오염된 버전**을 확인했다. 별개로, Open VSX 마켓플레이스에서는 정식 개발 도구를 사칭한 확장 프로그램 **77개**가 2026년 8월 3일자로 제거됐다.

**왜 눈여겨볼지**
`keyv`는 직접 설치한 기억이 없어도 전이 의존성으로 딸려 들어오는 대표적인 유틸 패키지다. 웜 형태라는 건 감염된 개발자 머신의 npm 토큰으로 다른 패키지를 자동 오염시킨다는 뜻이라, 확산 속도가 기존 타이포스쿼팅과 다르다. Open VSX 건은 VS Code 포크(Cursor, Windsurf 등)를 쓰는 경우 특히 해당된다 — 이들은 MS 마켓플레이스가 아니라 Open VSX를 쓴다.

✅ **오늘의 액션**
- `npm ls keyv` 로 전이 의존성 확인
- `npm audit` + lockfile 커밋 여부 점검
- 에디터 확장 목록에서 최근 설치한 것 중 발행자(publisher)가 낯선 것 정리

## 5. AI 코딩 도구 — 가격 체계 변화 주의

**요약**
Claude 계열에서는 **Sonnet 5**가 기본 모델로 자리 잡았고, MTok당 $2/$10의 프로모션 가격이 **8월 31일까지** 적용되는 것으로 알려졌다. GitHub Copilot 쪽은 사용량 기반(AI Credits) 과금으로 전환돼 좌석 요금 + 토큰/크레딧/에이전트 실행 초과분이 청구되는 구조가 됐다고 보도됐다. Cursor는 Composer 2와 병렬 에이전트를 밀고 있다. (※ 이 항목의 상당 부분은 비공식 비교 블로그 출처로, 정확한 조건은 각 사 공식 가격 페이지 확인 필요)

**왜 눈여겨볼지**
가격 체계가 좌석제에서 사용량제로 넘어가면, 개인 개발자의 월 비용은 "쓴 만큼"으로 바뀐다. 에이전트를 병렬로 여러 개 돌리는 워크플로우는 편리하지만 토큰 소모가 선형이 아니라 급격히 늘어난다. 프로모션 가격이 8월 말 종료된다면 9월 청구서는 체감이 다를 수 있으니, 지금 사용량 대시보드를 한 번 확인해두는 게 좋다.
