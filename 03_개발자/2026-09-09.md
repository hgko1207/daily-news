## 1. Bumblebee — Perplexity AI가 만든 오픈소스 공급망 스캐너

**요약**
읽기 전용(read-only) 공급망 스캐너. npm, PyPI, Go modules, RubyGems, Composer 패키지에 더해 **MCP 서버, 에디터 확장, 브라우저 확장**까지 악성·의심 의존성을 스캔한다.

**왜 눈여겨볼지**
스캔 대상에 MCP 서버와 에디터 확장이 포함됐다는 게 핵심이다. AI 코딩 도구를 쓰면 신뢰 경계가 `package.json`을 넘어 확장·MCP 서버로 넓어지는데, 이 영역은 그동안 감사 도구가 거의 없었다. 실무에 바로 붙일 만한 도구.

## 2. VoiceStudio — 완전 로컬 ElevenLabs 대안

**요약**
오픈소스·완전 로컬 음성 도구. 보이스 클로닝, 보이스 디자인, 영상 더빙, 받아쓰기, 전사, 오디오북 제작을 지원하며 646개 언어를 다룬다. 이번 달 7.5k 스타 획득.

**왜 눈여겨볼지**
음성 API를 쓰던 워크로드를 로컬로 내리면 비용과 데이터 유출 리스크가 동시에 줄어든다. 특히 사내 회의 전사처럼 외부 전송이 꺼려지는 데이터에 실용적. 로컬 우선(local-first) 흐름이 텍스트를 넘어 음성으로 넘어온 사례.

📄 https://trendshift.io/monthly

## 3. Archify — 검증 가능한 아키텍처 다이어그램

**요약**
아키텍처, 워크플로, 시퀀스, 데이터 플로, 라이프사이클 다이어그램을 "아름답고 검증 가능하게(verifiable)" 그리는 도구. 이번 달 13k 스타.

**왜 눈여겨볼지**
'verifiable'이라는 표현이 포인트다. 다이어그램이 실제 코드/구성과 어긋나 있는 문제는 어느 팀에나 있다. LLM이 다이어그램을 쉽게 생성하게 되면서, 오히려 "이 그림이 실제와 맞는가"를 검사하는 층이 중요해졌다.

📄 https://trendshift.io/monthly

## 4. Claude Code — 9월 초 연속 릴리스 (v2.1.258 ~ v2.1.261)

**요약**
- **v2.1.261** (9월 4일 배포): 최신 릴리스
- **v2.1.260**: 커밋되지 않은 변경사항을 **나란히 보는(side-by-side) diff 패널**로 표시 — 편집 내용을 실시간 리뷰 가능
- **v2.1.258**: 구형 Mac에서 앱이 실행되지 않던 문제 및 원격 세션 실패 수정
- 그 밖에 정책·스킬 진단(skill diagnostics), 인라인 명령/태스크 출력 한도 확대, VS Code 워크플로·모델 선택·Remote Control 개선

**왜 눈여겨볼지**
side-by-side diff 패널은 에이전트 코딩의 실질적 병목인 '리뷰 부담'을 겨냥한 변경이다. 에이전트가 만든 코드를 얼마나 빠르고 안전하게 검토하느냐가 생산성의 진짜 변수다. 스킬 진단 기능은 커스텀 스킬을 만들어 쓰는 경우 디버깅 시간을 크게 줄여준다.

📄 https://releasebot.io/updates/anthropic/claude-code

## 5. 프론티어 모델 API 단가 상승 — GPT-6 Astra $10 / $50 per 1M

**요약**
GPT-6 Astra의 API 가격은 입력 100만 토큰당 $10, 출력 $50. 직전 세대(GPT-5.6 Sol) 대비 약 2.5배다. 컨텍스트는 105만 토큰으로 크게 늘었다.

**왜 눈여겨볼지**
"모델은 계속 싸진다"는 가정이 이번 세대에서 깨졌다. 컨텍스트가 커지면 자연스럽게 요청당 토큰 소비도 늘어나므로, 단가 인상과 컨텍스트 확대가 겹치면 비용은 곱으로 증가한다. 에이전트 루프를 돌리는 구조라면 특히 주의. 작업별로 모델 티어를 나누는 라우팅 설계가 선택이 아니라 필수가 되는 국면이다.

📄 https://www.cnbc.com/2026/09/03/open-ai-astra-gpt-6-cyber.html
