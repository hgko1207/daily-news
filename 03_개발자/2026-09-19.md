## 1. "나는 패스키가 싫다" — 656점, 댓글 641개

**요약**

## 2. ZCode, 조용히 Git 히스토리를 클라우드로 업로드 — 205점

**요약**
ferstar.org의 분석 글로, ZCode라는 도구가 사용자 동의 없이 워크스페이스 스냅샷과 Git 히스토리를 클라우드에 업로드하고 있었다는 내용이다. 83개 댓글이 달렸다.

**왜 눈여겨볼지**
AI 코딩 도구를 쓰는 개발자라면 남의 일이 아니다. 에디터·확장·에이전트가 컨텍스트를 위해 읽어가는 범위는 대개 설정 화면에 다 적혀 있지 않다. Git 히스토리에는 과거에 커밋됐다 지워진 시크릿, 내부 URL, 고객명이 그대로 남아 있는 경우가 많다. 사내 코드에 AI 도구를 붙였다면 텔레메트리 설정을 한 번 열어볼 만하다.

## 4. Cloudflare — Quick Tunnels(400점), 수학으로 100TB RAM 절약(40점)

**요약**
Cloudflare Quick Tunnels가 400점으로 상위권에 올랐다. 로컬 서버를 설정 없이 공개 URL로 즉시 노출하는 터널링 도구다. 같은 날 Cloudflare 엔지니어링 블로그의 "Saving another 100TB of RAM with math (and Rust)" 글도 올라왔다.

**왜 눈여겨볼지**
Quick Tunnels는 로컬 개발 서버를 모바일 실기기나 외부 웹훅에 물려야 할 때 ngrok 대안으로 즉시 쓸 수 있다. RAM 절약 글은 확률적 자료구조와 Rust의 메모리 레이아웃 제어를 실제 프로덕션 스케일에서 적용한 사례라, 성능 최적화 사고방식을 익히기에 좋은 읽을거리다.

## 5. AI 코딩 도구 동향 — "LLM으로 글쓰기"(296점), "Conway 추측 증명을 vibe했다"(154점)

**요약**
sockpuppet.org의 "How to Write with an LLM"이 296점·209댓글, Dan Abramov(overreacted.io)의 "I vibed a proof of Conway's conjecture"가 154점·150댓글을 기록했다. 둘 다 LLM을 도구로 쓰는 실제 워크플로를 다룬다. 한편 AI 코딩 도구 가격은 9월 1일 전후로 여러 변화가 보도됐는데, GitHub Copilot의 포함 크레딧 축소와 Anthropic Sonnet 5 API 요율 관련 내용이 매체마다 엇갈리게 전해지고 있어 실제 요율은 각 벤더 공식 가격 페이지 확인이 필요하다.

**왜 눈여겨볼지**
"vibe coding" 담론이 코드에서 수학 증명으로 옮겨간 건 상징적이다. 검증 가능한 도메인에서는 LLM의 생성-검증 루프가 실제로 작동한다는 뜻이고, 반대로 검증 수단이 없는 도메인에서는 여전히 위험하다는 대조가 선명해진다. 가격 부분은 SEO성 비교 블로그들의 수치가 서로 충돌하므로 단정하지 않는 편이 안전하다.
