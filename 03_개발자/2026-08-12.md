### 1. AI 코딩 도구 시장 급성장 — 3강 구도 정착
- **요약:** 2026년 AI 코딩 도구 시장은 약 128억 달러로 2024년(51억)의 2배 이상. 전문 개발자의 90%가 하루 한 번 이상 사용. GitHub Copilot(엔터프라이즈)·Cursor(개발자 선호)·Claude Code(복잡 추론)로 역할 분담.
- **왜 눈여겨볼지:** 'Cursor로 일상 편집 + Claude Code로 난도 높은 작업'이 대표 스택으로 굳어지는 중. 본인 워크플로 최적화에 참고할 만하다.
- 📄 https://www.sitepoint.com/claude-code-vs-cursor-vs-copilot-the-2026-developer-comparison/

### 2. Cursor — Agent 모드·Composer로 멀티파일 자율 편집 강화
- **요약:** VS Code 오픈소스 기반의 Cursor가 2026년 Agent 모드(멀티파일 자율 계획·실행), Composer, 인라인 챗, 전체 프로젝트 컨텍스트 탭 완성 기능을 갖춤.
- **왜 눈여겨볼지:** 반복 리팩터링·다중 파일 수정 작업의 생산성을 크게 바꿀 수 있어 실무 도입 검토 가치.
- 📄 https://www.nxcode.io/resources/news/cursor-vs-claude-code-vs-github-copilot-2026-ultimate-comparison

### 3. GitHub Trending / 화제 리포지토리
- **요약:** GitHub 인기 리포 큐레이션(주간)에서 AI·에이전트 관련 프로젝트가 상위권을 유지. (github.com/trending에서 당일 목록 직접 확인 권장)
- **왜 눈여겨볼지:** 에이전트/보안 관련 오픈소스가 실제 코드 품질·보안 이슈와 맞물려 커뮤니티 논의가 활발.
