## 5. AI 코딩 도구 동향 — 툴 간 경계가 사실상 사라짐

**요약**
2026년 8월 시점으로 Claude Code·GitHub Copilot·Cursor 세 도구 모두 CLI를 제공하고, 에이전트 방식으로 코드를 실행하며, PR을 여는 클라우드 에이전트를 운영하고, MCP 서버에 연결된다. "터미널 vs IDE vs 자체 에디터"라는 구분 축이 무너졌다는 정리가 나온다. 가격 면에서는 $20/월 구간에 세 도구가 몰려 있고, GitHub Copilot Pro가 $10/월 사용량 기반 크레딧 모델로 아래를 받치는 구도.

⚠️ 출처 주의: 이 항목의 근거는 대부분 비교 리뷰형 블로그다. 구체적인 가격·모델 스펙 수치는 각 벤더 공식 문서로 재확인 필요. (모델 가격 변동 관련 서술은 교차 확인되지 않아 본문에서 제외했다.)

**왜 눈여겨볼지**
도구 선택 기준이 '어디서 돌아가는가'에서 '내 저장소·CI·MCP 구성에 어떻게 붙는가'로 옮겨갔다. 지금 쓰는 도구를 바꿀 이유가 있다면 기능 비교표가 아니라 기존 워크플로와의 접합부에서 찾는 게 맞다.

📄 [SitePoint — Claude Code vs Cursor vs Copilot: The 2026 Developer Comparison](https://www.sitepoint.com/claude-code-vs-cursor-vs-copilot-the-2026-developer-comparison/)
