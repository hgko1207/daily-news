## 🤖 AI 코딩 도구 동향

### 시장 점유율: Copilot 29%, Cursor·Claude Code 각 18%

**요약**
JetBrains 조사 기준 업무 사용률은 GitHub Copilot 29%로 1위, Cursor와 Claude Code가 각 18%로 2위 그룹이다. Claude Code는 Opus 4.6 기반으로 SWE-bench 80.8%(2026년 3월 기준 최고 점수), 1M 토큰 컨텍스트, Agent Mode, 터미널 통합을 제공한다. 여러 사용 리포트에서 타 도구 대비 약 30% 적은 코드 재작업이 보고됐다.

**왜 눈여겨볼지**
Copilot의 1위는 "IDE 기본 탑재"라는 유통 채널의 힘을 보여주고, Cursor/Claude Code의 동률은 에이전틱 워크플로가 별도 카테고리로 자리잡았음을 보여준다. 다만 이 수치들은 벤더 중립적이지 않은 비교 콘텐츠에서 재인용된 것이므로, 원 조사(JetBrains Developer Ecosystem Survey) 원문 확인을 권한다.
