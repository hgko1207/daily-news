## 3. QubesOS: copy-to-VM 오류 보고 백채널을 통한 임의 코드 실행 (215점)

**요약**

### 7. 2026년 AI 코딩 도구 지형 — MCP가 사실상 표준

**요약**
2026년 기준 AI 코딩 도구는 IDE 코파일럿 계열(Cursor, GitHub Copilot)과 터미널 에이전트 계열(Claude Code, Codex)로 갈렸고, Model Context Protocol(MCP)이 외부 도구 연결의 de facto 표준으로 자리 잡았다는 비교 분석들이 나온다. Cursor는 2026년 3월 기준 ARR 20억 달러, Copilot은 포춘 100대 기업 90% 이상 도입으로 보고된다. (수치는 각 매체 인용 기준)

**왜 눈여겨볼지**
도구 자체보다 'MCP를 지원하는가'가 선택 기준이 되고 있다. 사내 API·DB·이슈 트래커를 붙일 계획이 있다면, MCP 서버를 한 번 직접 만들어보는 것이 가장 빠른 학습 경로.
