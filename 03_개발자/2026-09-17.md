# 개발자 브리핑 — 2026-09-17 (목)

## 🔎 핵심 한두 줄

GitHub 트렌딩은 여전히 AI 에이전트·코딩 도구가 장악 중이고, 공급망 보안 스캐너(MCP 서버·에디터 확장까지 검사)가 눈에 띈다. AI 코딩 도구 3강은 모두 CLI·에이전트·MCP를 기본 탑재하며 기능이 수렴하고 있다.

---

## 1. Bumblebee — MCP 서버·에디터 확장까지 훑는 공급망 스캐너

- **요약:** Perplexity AI가 공개한 **읽기 전용(read-only) 공급망 스캐너**. 의존성뿐 아니라 **MCP 서버와 에디터 확장(extension)까지** 의심스러운 패키지를 검사한다. 2026년 AI 개발자가 주목할 리포지토리로 꼽혔다.
- **왜 눈여겨볼지:** MCP 서버와 VS Code/Cursor 확장은 지금 개발 환경에서 가장 빠르게 늘어나는 **검증 안 된 실행 표면**이다. 에이전트에 도구를 계속 붙이는 워크플로를 쓴다면, 의존성 스캔의 범위를 여기까지 넓혀야 한다는 신호다.
- 📄 링크: https://www.firecrawl.dev/blog/best-github-repos

## 2. GitHub Trending — AI 에이전트·로컬 우선(local-first) 도구가 주류

- **요약:** 9월 중순 트렌딩에는 `codex-with-chatgpt`(에이전틱 코딩), `wechat-intelligence-hub`(로컬 우선 메신저 인텔리전스 시스템), `human-atlas`(BodyParts3D 메시 2,234개를 선택 가능한 오픈소스 3D 해부학 탐색기), `Mac-Duo`(877 stars, 아이폰 Duo 효과를 맥북에) 등이 올랐다.
- **왜 눈여겨볼지:** 공통점은 **"클라우드 API 래퍼"에서 "로컬에서 돌고 내 데이터에 붙는 도구"로의 이동**이다. 개인 데이터(메신저 로그 등)를 로컬에서 인덱싱하고 LLM을 붙이는 패턴은 사내 도구 만들 때 바로 응용 가능한 설계다.
- 📄 링크: https://github.com/trending / https://github.com/marc-ko/daily-trending-repo/issues/550

## 3. AI 코딩 도구 — 기능 수렴, 가격 구조는 분화

- **요약:** 2026년 8월 기준 Copilot·Cursor·Claude Code 세 도구 모두 **CLI 제공 + 에이전트 방식 코드 실행 + PR을 여는 클라우드 에이전트 + MCP 서버 연결**을 공통 지원한다. 채택률은 Copilot 29%(직장 기준, 누적 2,600만+ 사용자), Cursor·Claude Code 각 18%로 집계됐으나 Copilot의 성장은 2024년 이후 정체됐다는 분석이다.
- **왜 눈여겨볼지:** 기능이 수렴했다는 건 **선택 기준이 "기능"에서 "가격·컨텍스트 품질·조직 정책"으로 넘어갔다**는 뜻이다. 어느 하나에 락인되지 않도록 MCP·CLI 기준으로 워크플로를 짜두는 게 유리하다.
- ⚠️ *비고: 위 수치는 비교 리뷰 매체 집계로, 벤더 공식 발표가 아니다. 참고용으로만 볼 것.*
- 📄 링크: https://www.sitepoint.com/claude-code-vs-cursor-vs-copilot-the-2026-developer-comparison/

## 4. 가격 동향 — Cursor 좌석 분화, Anthropic Sonnet 5 인상 철회

- **요약:** Anthropic은 9월 1일 예정했던 **Sonnet 5 가격 인상($2/$10 → $3/$15)을 철회**해 입력 $2 / 출력 $10(100만 토큰 기준)이 유지된다. Cursor는 팀 좌석 사용량 풀을 **자사 모델(Composer/Auto)용과 서드파티 API 모델(Claude·GPT·Gemini)용으로 분리**했고, Standard $40/월 유지 + **Premium $120/월(Standard의 5배 사용량)** 좌석을 신설했다. Copilot Pro는 $10/월로 유료 진입선이 가장 낮다.
- **왜 눈여겨볼지:** 에이전트를 매일 돌리면 구독료보다 **토큰 사용량이 실제 비용을 결정**한다. 좌석 요금제가 사용량 풀 단위로 쪼개지는 흐름이라, 팀 단위 도입 시 총비용 계산 방식을 다시 짜야 한다.
- 📄 링크: https://spectrumailab.com/blog/ai-coding-tools-pricing-compared-2026
