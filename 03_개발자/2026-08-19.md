## 1. DuckDB v2.0 프리뷰 (618 points)

**요약**
DuckDB가 2.0 하이라이트를 공개했다. 인프로세스 분석용 OLAP 엔진의 첫 메이저 버전업으로, HN에서 618포인트·112 코멘트를 기록하며 프론트페이지 최상위에 올랐다.

**왜 눈여겨볼지**
로컬에서 파케이/CSV를 SQL로 바로 다루는 워크플로가 이미 데이터 분석 표준에 가까워졌다. 메이저 버전은 파일 포맷·확장 API 호환성 변화를 동반하는 경우가 많으니, 파이프라인에 DuckDB를 쓰고 있다면 마이그레이션 노트를 먼저 읽는 게 좋다.

📄 https://duckdb.org/2026/08/17/duckdb-20-highlights

## 2. AI가 만든 Copilot "Autofix"가 Snowflake Jira 침해로 이어짐 (363 points)

**요약**
보안업체 Wiz가 GitHub Copilot의 AI 생성 "Autofix" 패치가 Snowflake의 Jira/CI-CD 파이프라인 침해에 악용된 과정을 공개했다.

**왜 눈여겨볼지**
AI 에이전트가 리포지토리에 쓰기 권한을 갖는 순간, 그 에이전트 자체가 공급망 공격 표면이 된다. 자동 수정·자동 PR 머지를 켜 둔 CI 설정이 있다면 권한 범위와 승인 게이트를 지금 다시 볼 만하다. 특히 CI 시크릿에 접근 가능한 잡에서 AI 생성 코드를 실행하는 구성이 위험하다.

📄 https://www.wiz.io/blog/red-agent-snowflake-copilot-cicd-bug

## 4. AI 코딩 도구·모델 동향

### GPT-5.6 Sol 서드파티 50% 할인 (395 points)
OpenRouter·Vercel AI Gateway에서 8/17~18부터 9/18까지 Sol 가격이 50% 인하됐다. OpenAI 공식 API는 $5/$30 그대로다. 별개로 roboflow는 "GPT-5.6 Sol이 OpenAI가 내놓은 최고의 비전 모델"이라는 벤치마크 글을 올려 336포인트를 받았다.

**왜 눈여겨볼지**
Terminal-Bench 2.1에서 GPT-5.6 Sol 89.5%(xhigh), Claude Opus 5 89.1%(max)로 코딩 성능은 사실상 백중세다. 성능이 비슷하면 남는 변수는 가격·레이턴시·툴 생태계다. Claude Sonnet 5의 $2/$10가 8월 15일부로 상시 요금이 되고 9월 1일 인상이 취소된 것도 같은 맥락.

📄 https://news.ycombinator.com/item?id=49337602 · https://blog.roboflow.com/openai-gpt-5-6/ · https://openai.com/index/gpt-5-6/

### The Benchmarkpocalypse — danluu (77 points)
벤치마크의 신뢰성 붕괴를 다룬 danluu의 글. 모델 성능 수치를 근거로 도구를 고르는 지금, "벤치마크가 무엇을 측정하지 못하는가"를 짚어준다.

📄 https://danluu.com/benchpocalypse/
