### 4. ⚠️ Cursor 마켓플레이스 악성 Claude Code 확장 사건 (10/29)
- **요약:** Cursor의 VS Code 확장 마켓플레이스에 Anthropic이 만들지 않은 변조본 `Anthropic.claude-code` 2.1.312·2.1.313(macOS·Windows)이 10/29 약 02:27~13:35(PT) 동안 배포됐다. 공격자 SSH 키(`svc-telemetry`) 추가, 리버스 SSH 터널, 지속성(LaunchAgent/예약 작업) 설치 시도. Cursor는 확장 삭제만으로는 부족할 수 있다며 전용 정리 스크립트와 자격증명 교체를 권고.
- **왜 눈여겨볼지:** 공식 확장 ID로 공급망 공격이 들어온 사례. Cursor를 쓴다면 `~/.ssh/authorized_keys`(Windows는 사용자·관리자 authorized_keys)에서 `svc-telemetry` 검색을 권장.
- 📄 [Cursor 보안 공지](https://cursor.com/blog/claude-code-extension-security-notice) · [The Hacker News](https://thehackernews.com/2026/10/official-claude-code-vs-code-extension.html)
