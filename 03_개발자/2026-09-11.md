## 🛠️ AI 코딩 도구 동향

### Copilot·Cursor·Claude Code — 기능은 수렴, 차별점은 가격·팀 기능으로 이동
**요약** 2026년 8월 기준 세 도구 모두 ① CLI 제공 ② 에이전틱 코드 실행 ③ PR을 여는 클라우드 에이전트 ④ MCP 서버 연결을 공통으로 지원한다. 9월 1일 기준 Copilot Pro가 월 $10로 최저가 유료 진입점이고, Claude Code·Codex·Cursor는 $20 선에서 시작하나 **에이전트를 매일 쓰면 현실적 예산은 월 $60~$200 수준**으로 올라간다는 분석이다. 시니어 개발자 설문에서는 Claude Code를 'most loved'로 꼽은 비율이 46%(Cursor 19%, Copilot 9%)였으나, 설치 기반은 여전히 Copilot이 최대다. 엔터프라이즈의 지배적 패턴은 "전사 Copilot(자동완성 베이스라인) + 시니어 주도 Claude Code(고레버리지 에이전틱 작업)" 조합.

**왜 눈여겨볼지** 기능이 수렴했다는 건 **도구 선택이 '성능 비교'에서 '비용 구조와 워크플로 적합성' 문제로 바뀌었다**는 뜻이다. 특히 토큰 기반 과금에서 실제 지출은 구독료가 아니라 사용량이 결정한다. 본인의 월 실사용량을 한 번 측정해보는 게 어떤 비교 글보다 정확하다.

⚠️ 참고: 위 수치들은 비교 블로그 출처이며 1차 자료(각 벤더 공식 가격 페이지)로 교차 확인 권장. 일부 매체에 언급된 "Cursor의 SpaceX 인수" 관련 내용은 정통 매체로 확인되지 않아 본 브리핑에서는 사실로 다루지 않는다.
