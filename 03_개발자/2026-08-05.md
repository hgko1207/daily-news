### 2. GitHub Copilot Coding Agent GA — 이슈→PR 자동화
- **요약:** Copilot Coding Agent가 정식 출시(GA)되며 GitHub 이슈를 할당하면 여러 파일 수정·CI 실행·PR 생성까지 자동 수행. Cursor는 v3.11에서 Side Chats(병렬 에이전트 대화)·Conversation Search·Cloud Agent Hooks 추가.
- **왜 눈여겨볼지:** 개발 워크플로가 '코드 자동완성'에서 '이슈 단위 위임'으로 이동. 반복 작업을 에이전트에 넘기는 습관을 들이면 생산성 차이가 크다.
- 📄 https://spectrumailab.com/blog/ai-coding-tools-pricing-compared-2026
