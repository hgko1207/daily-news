## 1. Claude Opus 5 출시 & AI 코딩 모델 지형 변화
**요약:** Anthropic이 7월 24일 Claude Opus 5를 $5/$25(입력/출력 100만 토큰)에 출시했다. 6월 30일 나온 Claude Sonnet 5(코드명 Fennec)는 100만 토큰 컨텍스트에 도입가 $2/$10(8/31까지, 이후 $3/$15). Cursor는 팀 시트를 1st-party 모델 풀과 서드파티 API 풀로 분리하고 파워유저용 Premium 시트($120/월)를 신설. GitHub Copilot은 6/1부터 사용량 기반 과금(1 AI 크레딧=$0.01)으로 전환.

**왜 눈여겨볼지:** 코딩 에이전트의 '가격·컨텍스트·과금 체계'가 빠르게 재편 중. 100만 토큰 컨텍스트가 표준이 되면 대형 코드베이스 전체를 넣는 워크플로가 현실화된다. 사용량 기반 과금 전환은 월 비용 예측을 어렵게 하므로 토큰 사용 모니터링이 필요.

## 2. GitHub, 공개 버그바운티 보상 대폭 삭감
**요약:** GitHub이 7월 27일부터 공개 버그바운티 보상을 전 등급에서 최소 절반 삭감했다. Critical은 기존 $20,000~$30,000+에서 고정 $10,000로 낮추고, 최고 보상은 초청제 VIP 티어($30,000+)로 이동했다.

**왜 눈여겨볼지:** 오픈 보안 리서치 생태계의 인센티브 구조 변화. 개인 연구자에겐 불리, 검증된 상위 연구자 중심으로 재편되는 흐름. 오픈소스 프로젝트 유지보수·보안 기여 동기에 영향을 줄 수 있다.

📄 https://thehackernews.com/2026/07/github-cuts-public-bug-bounty-payouts.html

## 3. 공급망 공격 — 악성 GitHub 저장소 7,600개 'FakeGit' 캠페인
**요약:** FakeGit 캠페인이 약 7,600개 악성 저장소(약 6,600개 프로필)를 통해 SmartLoader 멀웨어를 유포, GitHub Release 자산 기준 누적 1,400만+ 다운로드가 집계됐다. 이 중 약 800개는 개인·기업용 Skills 또는 MCP 서버로 위장했다.

**왜 눈여겨볼지:** MCP·Skills로 위장한 공급망 공격이 등장했다는 점이 핵심. 저장소 star 수나 이름만 믿지 말고, 출처·서명·다운로드 파일을 검증하는 습관이 필요하다.
