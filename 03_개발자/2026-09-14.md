### 1. 딥시크 V4.1 Flash — 코딩 벤치마크에서 상위 모델과 경쟁, 비용은 훨씬 낮게
**요약** 9월 11일 공개. 5,520억 파라미터 MoE, 최대 100만 토큰 컨텍스트, 텍스트+이미지 멀티모달. HBM 요구량 약 1/4, SSD 약 1/8로 낮췄고 API 가격도 인하했다. 코딩·사이버보안 벤치마크에서 GPT-5.6 Sol, Claude Opus 5를 앞섰다는 보도가 있으나(wccftech 등), 벤치마크 주장은 출처에 따라 편차가 크므로 실사용 검증이 필요하다.
**왜 눈여겨볼지** 추론 비용이 한 자릿수 배수로 떨어지면 "이 작업에 LLM을 쓸 만한가"의 손익분기가 바뀐다. 지금까지 비용 때문에 포기했던 배치 처리·대량 코드 분석 같은 워크로드를 재검토할 시점이다.

### 2. AI 코딩 도구 과금 체계 재편 — 크레딧/컴퓨트 기반으로 이동
**요약** 2026년 들어 GitHub Copilot이 전 요금제를 **사용량 기반 AI 크레딧 모델**로 전환했다(Pro: $10에 1,500 크레딧). Cursor는 컴퓨트 기반 과금으로, Pro $20 포함분 초과 시 온디맨드 요금이 붙는다. Claude Code는 유료 Claude 플랜에 포함되는 방식이다. 올해 Amazon Q Developer 신규 가입 중단(5월), Gemini Code Assist 개인 무료 접근 종료(6월)도 있었다.
