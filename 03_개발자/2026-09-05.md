## 5. AI 코딩 도구 업데이트 — Claude Fable 5.1, GitHub Copilot 정식 지원

**요약**
9월 1일 GitHub Copilot에서 Anthropic의 Claude Fable 5.1이 정식(GA) 제공 시작. 장기 실행·자율 코딩 작업(심층 코드베이스 리서치, 기능 개발, 복합 에이전트 워크플로)을 겨냥한 모델로, Copilot Pro+·Max·Business·Enterprise 사용자가 대상이다. 단, 다른 Claude 모델과 달리 안전 분류기 동작을 위해 기본적으로 데이터 보존(prompt·output 포함)이 요구되며, 일부 엔터프라이즈 고객만 zero data retention을 적용받는다.

**왜 눈여겨볼지**
"데이터 보존이 기본값"은 사내 코드에 붙일 때 반드시 확인해야 할 조건이다. 성능만 보고 스위치를 켜면 보안팀과 충돌한다.

📄 https://github.blog/changelog/2026-09-01-claude-fable-5-1-generally-available-in-github-copilot/
