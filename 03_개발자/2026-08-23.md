## 2. AutoGPT, 프레임워크에서 플랫폼으로

**요약**
AutoGPT는 GitHub AI 에이전트 카테고리에서 가장 많은 스타를 받은 프로젝트로, 2026년에는 블록 기반 비주얼 빌더, 사전 패키징된 에이전트 마켓플레이스, 프로덕션급 셀프호스팅을 갖춘 **플랫폼**으로 진화했다.

**왜 눈여겨볼지**

## 3. AI 저장소 폭증 — LLM 관련 리포지터리 전년 대비 +178%

**요약**

## 4. AI 코딩 도구 지형 — 3강 구도와 조합 사용의 정착

**요약**
2026년 AI 코딩 시장은 GitHub Copilot(엔터프라이즈 도입 1위, 워크플레이스 채택률 29%, 누적 2,600만+ 사용자), Cursor(민첩성 선호, 18%), Claude Code(복잡한 추론 강점, 18%)의 3강 구도다. 가장 흔한 조합은 **"Cursor로 일상 편집 + Claude Code로 복잡한 작업"** 또는 **"IDE에는 Copilot + 터미널에는 Claude Code"**다.

**왜 눈여겨볼지**
하나의 도구로 통일하려는 시도보다, 작업 성격에 따라 나눠 쓰는 쪽이 실무에서 이미 표준이 됐다. 반복적인 자동완성과 다단계 리팩터링은 요구하는 모델 특성 자체가 다르다.
