## 🤖 AI 코딩 도구·모델 동향
### 1. GitHub Copilot Fusion 정식 출시 (10/28, Universe)
- **요약:** 작업마다 어떤 모델을 쓸지 자동으로 고르고 조합하는 기능이다. Standard·High·Max 세 가지 노력 수준과 Single·Cascade·Critique 오케스트레이션을 지원한다. 모든 Copilot 플랜에서 VS Code, Copilot 앱, CLI, JetBrains에 제공된다. 요금은 사용한 모델별 표준 단가로 청구되며, 한시적으로 유료 플랜 사용자에게 30% 할인이 적용된다. 로컬 모델 선택도 지원한다.
- **왜 눈여겨볼지:** 개발자가 모델을 직접 고르던 방식에서 오케스트레이션 레이어가 고르는 방식으로 바뀌는 흐름이다. 비용 구조는 실제로 써 보며 확인해야 한다.
- 📄 https://github.blog/changelog/2026-10-28-route-and-orchestrate-models-with-github-copilot-fusion/

### 2. GitHub Enterprise에 Copilot 포함 (10/28)
- **요약:** 계정팀과 계약하는 GitHub Enterprise Cloud 고객은 라이선스 사용자 전원이 Copilot을 쓸 수 있다. 좌석 단위가 아니라 엔터프라이즈 예산 기준으로 사용량을 계량하며, 기본 제공량은 없다. 예산이 소진되면 자동완성은 계속 쓸 수 있지만 Chat·코드리뷰는 멈춘다. Enterprise 라이선스가 없는 사용자는 Copilot Standalone(월 10달러)으로 같은 접근을 얻을 수 있다.
- **왜 눈여겨볼지:** 회사에서 AI 코딩 도구 비용을 관리하는 방식이 '좌석'에서 '토큰 예산'으로 넘어가는 신호다.
- 📄 https://github.blog/changelog/2026-10-28-github-enterprise-now-includes-access-to-github-copilot/
