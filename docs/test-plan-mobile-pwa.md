## 디자인 점검 수정 (2026-10-11)
- 제호 아래 "HH:mm 도착"은 그날 브리핑 첫 커밋 시각, 앱만 배포해도 바뀌지 않음 on 오늘
  Value: protects=도착 시각과 빌드 시각 분리; fails_when=generatedAt으로 되돌아가거나 얕은 체크아웃에서 앱 커밋 시각이 나옴; why_new=신규 필드 arrivedAt; seam=git log
- 얕은 체크아웃이면 도착 시각을 비우고 경고(틀린 시각 대신 표시 안 함) on 빌드
- 검색 미리보기에 표 문법(`|---|`, `| 지수 |`) 없음, 표 숫자("코스피 6,625.93")는 계속 검색됨 on 검색
  Value: protects=toPlain 표 변환; fails_when=표 행까지 지워 숫자 검색이 안 되거나 구분 줄이 남음; why_new=신규 변환; seam=none
- 10:30 전 오늘 파일이 없으면 호수 줄 오른쪽에 "오늘 브리핑 10시쯤 도착", 본문에 따로 안내 줄 없음. 날씨 줄에 "오늘/내일" on 오늘
- 말씀 출처("— 잠언 25:11", "16장 3절", "(골로새서 3:23, …)")가 오늘 탭·상세 모두 본문과 분리되어 작은 고딕 on 오늘/상세
- 상세 제목에서 날짜·요일이 빠지고 한글날·국내 휴장 같은 정보는 제목 아래 남음, 형식이 다른 제목은 원문 그대로 on 상세
