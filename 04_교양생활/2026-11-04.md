## 📚 지식 한 조각 — 메모리 가격은 어떻게 정해질까
HBM은 GPU 업체와 **연 단위**로 물량·가격을 미리 계약하는 맞춤형 제품이고, 범용 D램은 **분기(또는 월) 단위** 고정거래가격으로 거래됩니다. 그래서 범용 D램 가격이 갑자기 뛰면 그 상승분이 바로 반영되는 범용 제품이, 이미 가격이 묶인 HBM보다 일시적으로 더 남는 '역전'이 생길 수 있습니다. 최근 DDR4 8Gb 고정가가 1년 새 약 4배가 된 것이 바로 그 사례입니다.

## 📚 오늘의 한 입 학습 — `git worktree`
하나의 저장소에서 여러 브랜치를 **서로 다른 폴더에 동시에** 체크아웃하는 기능입니다.
```bash
git worktree add ../feature-a feature-a   # 새 폴더에 feature-a 브랜치 체크아웃
git worktree list                          # 현재 워크트리 목록
git worktree remove ../feature-a           # 정리
```
stash 없이 핫픽스와 기능 개발을 병행하거나, AI 코딩 에이전트 여러 개를 브랜치별로 동시에 돌릴 때 유용합니다(오늘 Trending의 worktrunk가 이를 감싼 도구).
