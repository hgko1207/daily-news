# 글로벌 기업·기술 브리핑 — 2026-09-06 (일)

## 🔎 핵심 한두 줄
OpenAI가 GPT-6 Astra를 공개하며 '컴퓨터 사용' 에이전트 경쟁을 한 단계 끌어올렸고, 같은 주 Chrome V8 제로데이가 실제 공격에 악용돼 전 세계 Chromium 기반 앱에 긴급 패치 압력이 걸렸다.

### 1. OpenAI, GPT-6 Astra 공개 (9/3~9/4)
- **요약:** OpenAI가 9월 3일 신뢰 파트너 대상 제한 프리뷰로 GPT-6 Astra를 공개하고, 다음 날 유료 사용자에게 사이버보안 등 일부 영역 요청을 거부하는 제한 버전을 배포했다. 컴퓨터 사용(computer use), 소프트웨어 엔지니어링, 다단계 워크플로 수행이 강점으로 제시됐고, ChatGPT Plus·Pro·Business·Enterprise와 API·AWS로 단계적 롤아웃. API 가격은 입력 100만 토큰당 $10, 출력 100만 토큰당 $50로 보도됐다.
- **의미:** 모델 경쟁의 축이 '답변 품질'에서 **'사람 대신 컴퓨터를 조작해 일을 끝내는 능력'** 으로 넘어갔다. 동시에 7월 사고 이후 안전장치를 덧붙이며 출시가 늦춰졌다는 점은, 앞으로 에이전트 모델의 출시 속도가 안전 검증에 묶일 것을 시사한다.
- **생각해볼 점:** 출력 토큰이 입력의 5배 가격이다. 에이전트가 길게 '생각하고 행동하는' 워크플로일수록 비용이 출력 쪽에서 폭발한다 — 벤치마크 점수보다 **단위 작업당 비용**을 먼저 재보는 게 실무적이다.
- ✅ **액션:** 업무에 LLM API를 쓰고 있다면, 지금 쓰는 모델의 입력/출력 토큰 비중을 한 번 뽑아보고 GPT-6 Astra 단가를 대입해 월 비용을 시뮬레이션해볼 것.
- 📄 링크: https://www.cnbc.com/2026/09/03/open-ai-astra-gpt-6-cyber.html / https://fortune.com/2026/09/03/openai-debuts-gpt-6-astra-computer-use-greg-brockman-says-start-of-agi/ / https://www.aljazeera.com/economy/2026/9/4/openai-unveils-gpt-6-astra-amid-rising-scrutiny-and-safety

### 2. Chrome V8 제로데이 CVE-2026-85046, 실제 공격에 악용
- **요약:** 구글이 9월 3일 Chrome V8 엔진의 type confusion 취약점(CVE-2026-85046) 패치를 배포했다. 악의적 JavaScript/HTML로 샌드박스 내 임의 코드 실행이 가능하며, 배포 시점에 이미 실제 악용(in the wild)이 확인됐다. 권고 버전은 Windows·macOS 152.0.7977.82/.83, Linux 152.0.7977.82. CISA는 9월 4일 KEV 목록에 등재하고 연방기관 대응 기한을 9월 16일로 설정했다.
- **의미:** V8은 Chrome뿐 아니라 Edge·Electron 등 Chromium 기반 데스크톱 앱 전반에 들어간다. 브라우저만 업데이트했다고 끝이 아니다.
- **생각해볼 점:** 사내에 Electron 기반 도구(예: 여러 데스크톱 앱)를 쓰고 있다면, 그 앱들의 Chromium 버전은 벤더 업데이트를 기다려야 한다. **의존성 사슬의 가장 느린 곳이 실제 노출 기간**을 결정한다.
- ✅ **액션:** 오늘 Chrome을 `chrome://settings/help`에서 152.0.7977.82 이상으로 업데이트. 개발 중인 Electron 앱이 있다면 Electron 버전과 번들 Chromium 버전을 확인.
- 📄 링크: https://thehackernews.com/2026/09/google-releases-chrome-update-to-patch.html / https://www.helpnetsecurity.com/2026/09/04/google-chrome-zero-day-cve-2026-85046/ / https://nvd.nist.gov/vuln/detail/cve-2026-85046

### 3. Anthropic, 페르마의 마지막 정리 형식화(Lean 4) 공개
- **요약:** Anthropic이 페르마의 마지막 정리를 Lean 4로 형식화하는 연구를 공개했고, 관련 저장소(`anthropics/fermats-last-theorem`)가 함께 공개돼 개발자 커뮤니티에서 크게 회자됐다.
- **의미:** 형식 증명은 "정답처럼 보이는 것"과 "검증된 정답"을 기계적으로 구분한다. LLM의 고질적 약점인 환각을 우회하는 가장 단단한 접근 중 하나다.
- **생각해볼 점:** 이 발상은 수학 밖에서도 통한다. AI가 만든 코드를 **타입 시스템·테스트·정적 분석이라는 형식적 관문**에 통과시키는 구조를 갖췄는지가, 앞으로 AI 코딩 생산성의 실질적 상한을 정한다.
- ✅ **액션:** AI로 코드를 생성한다면, 생성 직후 자동으로 타입 체크·테스트가 도는 파이프라인이 있는지 점검.
- 📄 링크: https://www.anthropic.com/research/formalizing-fermats-last-theorem / https://github.com/anthropics/fermats-last-theorem

### 4. Mullvad, 공개 암호화 DNS 중단 — Quad9 후원으로 전환
- **요약:** VPN 업체 Mullvad가 자사 공개 암호화 DNS 서버 운영을 중단하고 대신 Quad9을 후원하겠다고 밝혔다.
- **의미:** 프라이버시 인프라를 '각자 운영'에서 '공용 비영리에 집중'으로 옮기는 흐름. 중복 운영의 비용과 중앙화 리스크 사이의 트레이드오프다.
- **생각해볼 점:** 무료 공개 인프라에 의존하는 설정(개인 라우터의 DoH 주소 등)은 어느 날 조용히 사라질 수 있다. **내가 쓰는 무료 서비스의 지속 가능성**을 가끔은 점검할 필요가 있다.
- ✅ **액션:** 라우터나 OS에 Mullvad DNS를 직접 설정해뒀다면 대체 주소로 변경.
- 📄 링크: https://mullvad.net/en/blog/shutting-down-our-public-encrypted-dns-servers-and-sponsoring-quad9-instead
