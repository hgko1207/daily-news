### 1. 인텔 하루 28.6% 폭락 — 반도체 전반 동반 급락
- **요약:** 10/30 인텔이 시장 기대에 크게 못 미치는 4분기 전망을 내놓으며 하루 -28.58%, 시가총액 약 1,200억 달러 증발. 1974년 이후 최대 일일 낙폭으로 보도됨. 이날 AMD -10.9%, ASML ADR -6.6%, TSMC ADR -6.0%, 마이크론 -5.3%, 엔비디아 -4.2%.
- **의미:** PC 수요 부진과 메모리 원가 상승이 동시에 언급되어, ‘메모리 가격 상승 = 다운스트림 원가 부담’이라는 양면성이 부각됨.
- **생각해볼 점:** 메모리 업체엔 호재인 가격 상승이 고객사 수요를 깎는 구간에 들어섰는지가 관건.
- ✅ **액션:** 이번 주 AMD(11/3)·퀄컴·Arm(11/4) 실적 코멘트에서 PC·스마트폰 수요와 메모리 원가 언급 체크.

### 2. 알파벳·아마존, 클라우드 호실적에도 주가 급락 — ‘현금 경고등’
- **요약:** 구글 클라우드 매출 +103%, AWS +39%로 고성장했지만, 알파벳은 분기 설비투자 514억 달러로 잉여현금흐름 -91억 달러(2분기 연속 적자), 주가 하루 -12.6%. 아마존은 분기 설비투자 약 773억 달러, 최근 12개월 잉여현금흐름이 -424억 달러로 전환.
- **의미:** 시장의 질문이 ‘AI 수요가 있나’에서 ‘투자를 회수할 현금이 제때 나오나’로 바뀜.
- **생각해볼 점:** 빅테크 capex가 줄지 않는 한 HBM·서버 수요는 유지되지만, 투자자 압박으로 capex 가이던스가 꺾이면 반도체 밸류체인 전체가 영향.
- ✅ **액션:** 애플 실적(한국시간 11/3 새벽)에서 메모리 원가에 따른 마진 언급 확인.

- 📄 https://zdnet.co.kr/view/?no=20261030105016

### 3. 국제유가 100달러대 — 미·이란 협상 기대에 소폭 하락

### 4. GitHub ‘Copilot Fusion’ 정식 출시
- **요약:** 10/28 GitHub Universe에서 공개. 작업마다 단일 모델 또는 여러 모델 조합을 런타임에 자동 선택하는 오케스트레이션 엔진. Artificial Analysis 측정 기준 과제당 평균 비용 5.59달러로 Claude Code(Opus 5.5 Max, 11.42달러) 대비 약 51% 저렴, 코딩 에이전트 지수는 60 대 62로 근접. 유료 구독자는 한시적으로 모델 비용 30% 할인.
- **의미:** 경쟁 축이 ‘가장 좋은 모델’에서 ‘비용 대비 성능을 위한 모델 라우팅’으로 이동.
- **생각해볼 점:** 저장소 단위 변경 평가(FrontierCode)에선 51 대 56으로 뒤져, 큰 리팩터링엔 여전히 차이가 있음.
- ✅ **액션:** 사이드 프로젝트에서 같은 작업을 Fusion과 기존 도구로 돌려 비용·품질 비교.
